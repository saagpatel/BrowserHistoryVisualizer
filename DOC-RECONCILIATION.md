```

```
(no virtualenv creation). However, the `make dev` target (`Makefile:70`) executes:
```

```
where `VENV = backend/venv`. If a user follows the README install steps and runs `pip install`
globally without creating `backend/venv`, `make dev` will fail at the `source` line because
`backend/venv/bin/activate` does not exist. The manual uvicorn invocation in the README would
work with a global install, but `make dev` (the "recommended" path) would not.

**Change made to `README.md`:**
- Before: `pip install -r backend/requirements.txt`


  This makes the quick-start consistent with `make dev`'s venv assumption (`Makefile:70`).
