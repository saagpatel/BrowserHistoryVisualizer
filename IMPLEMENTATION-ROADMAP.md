# Browser History Visualizer — Implementation Roadmap

## Architecture

### System Overview
```
[Chrome History SQLite]  [Atlas History SQLite]  [Comet History SQLite]
           ↓                      ↓                       ↓
      [detector.py — glob ~/Library/.../*/Default/History, validate Chromium schema]
           ↓
      [extractor.py — read-only WAL open, copy to $TMPDIR on lock, query urls JOIN visits]
           ↓
      [processor.py — normalize timestamps, clean URLs, infer duration, dedup]
           ↓
      [categorizer.py — static allowlist → categories.json cache → Claude API batch]
           ↓
      [analytics.py — compute all 5 datasets, write analytics_cache.json]
           ↓
      [FastAPI :8000 (127.0.0.1 only) — /api/* routes, API-only, no static files]
           ↓
      [nginx :8080 (127.0.0.1 only)]
           ├── /api/*  → reverse proxy to FastAPI :8000
           └── /*      → frontend/dist/ static files (SPA fallback to index.html)
           ↓
      [React frontend — fetches GET /api/all on load, filters client-side on date change]
```

### Data Models

**Pydantic models (`backend/models.py`):**
```python
from pydantic import BaseModel
from typing import Literal, Optional

class HeatmapDay(BaseModel):
    date: str                              # "YYYY-MM-DD"
    count: int
    intensity: Literal[0, 1, 2, 3, 4]

class TopicSlice(BaseModel):
    category: str
    visits: int
    estimated_minutes: int
    percentage: float

class DomainRankEntry(BaseModel):
    domain: str
    category: str
    visit_count: int
    estimated_minutes: int

class ProductivityPoint(BaseModel):
    hour: int                              # 0–23
    focus_minutes: int                     # work + research + devtools
    distraction_minutes: int               # social + entertainment
    ratio: float

class RabbitHoleNode(BaseModel):
    id: str
    domain: str
    title: str
    category: str

class RabbitHoleSession(BaseModel):
    session_id: str
    start_time: int                        # Unix timestamp
    duration_minutes: int
    visit_count: int
    dominant_topic: str
    nodes: list[RabbitHoleNode]
    edges: list[tuple[str, str]]

class DetectedBrowser(BaseModel):
    name: str                              # "chrome" | "atlas" | "comet"
    path: str
    visit_count: int
    detected: bool
    manual_override: bool

class AppStatus(BaseModel):
    browsers: list[DetectedBrowser]
    total_visits: int
    date_range_available: tuple[str, str]  # ("YYYY-MM-DD", "YYYY-MM-DD")
    last_refreshed: Optional[int]          # Unix timestamp

class AllDatasets(BaseModel):
    status: AppStatus
    heatmap: list[HeatmapDay]
    topics: list[TopicSlice]
    domains: list[DomainRankEntry]
    productivity: list[ProductivityPoint]
    rabbit_holes: list[RabbitHoleSession]

class CategoryOverride(BaseModel):
    category: str

class BrowserPathOverride(BaseModel):
    browser: str
    path: str
```

### API Endpoints

| Endpoint | Method | Query Params | Response | Notes |
|----------|--------|-------------|----------|-------|
| `GET /api/status` | GET | — | `AppStatus` | Health check, detected browsers |
| `GET /api/all` | GET | `start`, `end` (YYYY-MM-DD) | `AllDatasets` | All 5 datasets in one call |
| `POST /api/refresh` | POST | — | `AppStatus` | Re-runs pipeline.py, invalidates cache |
| `POST /api/categorize` | POST | — | `{classified: int, cached: int, api_calls: int}` | Claude API batch for uncategorized domains |
| `GET /api/categories` | GET | — | `dict[str, str]` | All domain→category mappings |
| `POST /api/categories/{domain}` | POST | body: `CategoryOverride` | `{ok: true}` | User override, source: "user" |
| `GET /api/settings` | GET | — | `list[DetectedBrowser]` | Detected + manual path overrides |
| `POST /api/settings` | POST | body: `BrowserPathOverride` | `{ok: true}` | Store manual path override |

**`GET /api/all` is the primary endpoint.** The frontend calls this once on load and once when the date range changes. Single call, single response — no parallel fetching needed.

## Scope Boundaries

**In scope:**
- Chrome, Atlas, Comet browser support (Chromium SQLite schema)
- 5 visualizations: heatmap, topic donut, rabbit hole graph, domain ranking, productivity curve
- Hybrid categorization: static allowlist → Claude API batch (cached permanently)
- User-editable category overrides via Settings screen
- Date range picker filtering all charts client-side
- Daily 6am pipeline refresh via launchd + manual refresh button
- nginx :8080 → FastAPI :8000 serving architecture
- macOS only (launchd, ~/Library paths)

**Out of scope:**
- Firefox support (different SQLite schema — deferred, not designed for)
- Safari history (binary plist format, requires different parser)
- Cloud sync or multi-machine support
- User accounts or authentication
- History export/sharing features
- Mobile or Windows support

**Deferred (post-MVP):**
- Firefox support (Phase 5+, separate schema branch in extractor.py)
- URL-level drill-down (clicking a domain shows individual pages)
- Week-over-week trend comparison view
- Keyword search across page titles

## Security

- **FastAPI binding:** `127.0.0.1:8000` only — unreachable from outside the machine or from the browser directly
- **nginx binding:** `127.0.0.1:8080` only — loopback only, no external exposure
- **No CORS config in FastAPI** — single origin (localhost:8080), nginx is the only caller of :8000
- **SQLite access:** Read-only URI mode (`sqlite3.connect(f"file:{path}?mode=ro", uri=True)`). On `OperationalError`, copy to `$TMPDIR/bhv_[md5].db` with `os.chmod(0o600)`. Temp files cleaned via `atexit.register(cleanup_tmp)`.
- **Claude API key:** Read from `os.environ["ANTHROPIC_API_KEY"]` only. Injected by Makefile `sed` into `com.bhv.server.plist` at install time. Never in `.env`, never committed. `*.plist` and `bhv.conf.installed` in `.gitignore`.
- **categories.json:** Domain names only — no URLs, no titles, no visit data.
- **No telemetry:** Zero analytics SDKs, zero CDN dependencies.

## Phase 0: Python Data Pipeline (Week 1)

**Objective:** All 3 browsers detected, visits extracted, normalized, and cached as analytics JSON. Zero UI. The entire data pipeline working end-to-end.

**Tasks:**
1. Scaffold project directory, create `backend/venv`, install dependencies from requirements.txt, create `backend/data/` directory — **Acceptance:** `python -c "import fastapi, pandas, anthropic; print('ok')"` prints `ok`
2. `config.py` — define all constants: `SESSION_GAP_S=900`, `DURATION_CAP_S=1200`, `RABBIT_MIN_VISITS=4`, `RABBIT_MIN_DURATION_S=600`, `RABBIT_MIN_DOMAINS=2`, `AI_BATCH_SIZE=50`, `CATEGORY_TAXONOMY = ['work','research','social','news','entertainment','shopping','devtools','uncategorized']` — **Acceptance:** `from config import SESSION_GAP_S; assert SESSION_GAP_S == 900`
3. `detector.py` — glob `~/Library/Application Support/*/Default/History`; for each candidate, open with sqlite3 and run `SELECT name FROM sqlite_master WHERE type='table'`; keep only files where result contains both `urls` and `visits`; return `list[dict]` with `name` (guessed from path), `path`, `detected=True` — **Acceptance:** `python detector.py` prints ≥1 entry with your Chrome path; no Electron false positives
4. `extractor.py` — `extract_all() -> pd.DataFrame`: for each detected path, try `sqlite3.connect(f"file:{path}?mode=ro", uri=True)`; on `OperationalError`, copy to `$TMPDIR/bhv_{md5(path)}.db` and retry; query `SELECT u.url, u.title, u.visit_count, v.visit_time, v.from_visit FROM urls u JOIN visits v ON u.id = v.url`; tag each row with `browser` column; return concatenated DataFrame — **Acceptance:** `python extractor.py` prints total row count per browser; no crash if Atlas/Comet absent
5. `processor.py` — `process_visits(df) -> pd.DataFrame`: convert Chrome microseconds-since-1601 to Unix seconds (`ts / 1e6 - 11644473600`); extract domain via `urllib.parse.urlparse`; filter rows where URL starts with `chrome-extension://`, `chrome://`, `about:`, or has empty domain; infer duration as `min(next_visit_time - visit_time, DURATION_CAP_S)` within same browser, sorted by time; add `is_duration_estimated=True` to all rows — **Acceptance:** Zero null domains in output; all `duration_seconds` ≤ 1200; timestamp spot-check: known Chrome ts → correct datetime
6. `allowlist.py` — `ALLOWLIST: dict[str, str]` with 500 entries covering top global domains across all 8 categories. Must include: google.com, github.com, stackoverflow.com, reddit.com, youtube.com, twitter.com/x.com, linkedin.com, slack.com, notion.so, figma.com, jira.atlassian.com, amazon.com, netflix.com, wikipedia.org, nytimes.com, and 485 others — **Acceptance:** All 15 spot-check domains return correct category
7. `categorizer.py` — `categorize_visits(df) -> pd.DataFrame`: load `ALLOWLIST`; load `data/categories.json` if exists; for each unique domain, check allowlist first (source: "static"), then cache (source: "ai" or "user"), else mark "uncategorized"; write updated `categories.json`; return df with `category` column — **Acceptance:** `python categorizer.py --stats` prints `Static: ~80% | Cached: N% | Uncategorized: ~20%`
8. `analytics.py` — `compute_all(df) -> dict` computing all 5 datasets (heatmap, topics, domains, productivity, rabbit_holes — see schemas above); `save_cache(data)` writes to `data/analytics_cache.json`; `load_cache() -> dict | None` returns None if file absent or >24h old — **Acceptance:** `python analytics.py` produces `data/analytics_cache.json` with all 5 keys; valid JSON; no exceptions on real Chrome data
9. `pipeline.py` — standalone script calling extract→process→categorize→compute_all→save_cache in sequence; print timing for each step; exit 0 on success, exit 1 on any exception with full traceback — **Acceptance:** `time python pipeline.py` completes in < 10s; `analytics_cache.json` mtime updates; re-run is idempotent

**Verification checklist:**
- [ ] `python detector.py` → ≥1 browser detected, path exists on disk
- [ ] `python extractor.py` → prints `chrome: N visits` with N > 0
- [ ] `python processor.py` → prints `Processed: N clean, M filtered` with M < 10% of N

- [ ] `python pipeline.py` → exits 0, `data/analytics_cache.json` exists, all 5 keys present
